# Product profiles

One file per product: `<product>.md`. Read it at step 1; create it on the first video for a new
product and keep it updated with every decision the user takes, so the next video starts there.

## Template
```
# <Product>: launch video profile
## The story        what it does, for whom (the ICP in their own words), what makes it different
## Claims           allowed (source for each number), banned phrases, price/CTA wording and source
## Brand            where the manual lives, where the site source lives, which governs marketing,
                    colors, type roles, motion, mascot, logo, voice rules
## Real UI          where the product runs, how to launch it locally, how to seed a showable case,
                    capture gotchas, screens that make good surfaces
## Site components  animated components on the site worth rebuilding (paths)
## Past videos      date, bar, case used, score, what the user said, where the files are
## Decisions taken  the user's standing calls (caption policy, third-party UI, music taste, formats)
```
